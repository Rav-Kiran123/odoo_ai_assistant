Odoo AI Assistant

An independent AI application for Odoo 19 Community.

  • Colorful magic-wand button in the native navigation bar.
  • Resizable quick chat, a full chat in the AI Assistant app, and native Discuss conversations.
  • OpenAI, Claude, Gemini, and OpenRouter with live model catalogues.
  • Administrator-managed settings and per-user access on the user's Access Rights tab.
  • Permission-checked Odoo data reads and confirmed business actions through MCP tools.
  • Usage dashboard: tokens, API calls and active users across all users.
  • Local attachment staging, attachment reads, custom tools and operation audit.

Getting started

Open AI Assistant > Configuration > Settings to enable the app, configure a provider key, and select a model. Grant access on each user's Access Rights tab (AI > AI Assistant). Reload Odoo to see the magic wand.

Local by default

Typed chat messages are sent to the selected AI provider. Odoo record-query results stay local unless an administrator enables sharing and you approve Share and continue for a specific native result or attachment. Every data-changing action requires a preview and confirmation. External MCP connections are separate and are not needed for native chat. Never paste confidential data into chat.

API keys are restricted to administrators but are not encrypted at rest.
